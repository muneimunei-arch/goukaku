# 予備試験 合格管理 — 2026年10月18日・一行ずつ復習版

## 使い方

1. 学習履歴のメモで「復習日を指定」を押し、最初の復習日を選んで保存します。
2. その日になったら「復習」ページで対象を開きます。最初は本文を隠し、「進む」または本文枠のタップで、入力した改行ごとに一行ずつ追加表示します。「戻る」で直前の一行を隠します。
3. 最後まで確認したら「復習を終えて次回日を決める」で次の日程を選びます。「次回は未定」も選べます。

対象は学習履歴のメモ全文です。〈論証〉タグの外も含め、空行や黄色マーカーを保持します。長い一行は画面幅で折り返します。新しい貼り付けや採点入力は不要です。途中で閉じても表示位置を保存し、再開できます。

復習日を自動設定しません。以前削除した復習予定・採点履歴は再登録せず、退避済みバックアップを保持します。今回自分で登録した予定と完了履歴を独立して保存します。完了時のメモも履歴に保存します。

## データ保全

学習履歴・元メモ・進捗を継続利用します。更新前の全データをブラウザ内に自動退避し、設定の完全バックアップ・復元から書き出せます。完全JSONとCSVの両方に、新しい予定・途中位置・完了履歴を含めます。旧CSV・JSONも読み込めますが、旧自動復習は復活させません。

同じ公開URL・同じブラウザで利用してください。端末間の自動同期はありません。ブラウザのデータ消去に備え、設定から完全バックアップをファイルとして保管してください。個人の学習データは公開リポジトリに含めません。
