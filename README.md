## 論証の復習（2026年9月27日版）

`index.html` は、CSSとJavaScriptをすべて内包した単一ファイル版です。

## Vercel

1. `index.html` と `README.md` をGitHubリポジトリのルートに置きます。
2. Vercelでそのリポジトリを読み込みます。
3. Framework Presetは `Other`、Build Commandは空欄、Output Directoryは `.` にします。

## GitHub Pages

`index.html` をリポジトリのルートに置き、GitHub Pagesの公開元をそのブランチのルートに設定します。

学習記録はブラウザのローカルストレージに保存されます。別の公開先や端末へ移る場合は、アプリの設定画面からCSVを書き出し、新しい環境で読み込んでください。
