# 予備試験 合格管理 — GitHub / Vercel版

`vercel-package/index.html` は、CSSとJavaScriptをすべて内包した単一ファイル版です。

## 今回の更新

- 学習履歴を下へスクロールした後、画面上部へ勝手に戻らないよう修正
- 学習履歴・復習・毎日の記録の編集画面に黄色マーカーを追加
- 復習項目に編集ボタンを追加
- 入力した改行と黄色マーカーを一覧表示にも反映

## Vercel

1. `vercel-package` フォルダをGitHubリポジトリのルートに置きます。
2. Vercelでそのリポジトリを読み込みます。
3. Framework Presetは `Other`、Build Commandは空欄、Output Directoryは `.` にします。

## GitHub Pages

`vercel-package/index.html` をリポジトリのルートに置き、GitHub Pagesの公開元をそのブランチのルートに設定します。

ZIP版を使う場合は、ZIPを展開して中の`index.html`と`README.md`をリポジトリのルートへアップロードしてください。

## 黄色マーカーの使い方

編集画面で文字を選択し、「黄色マーカー」を押します。同じ箇所を選択してもう一度押すと解除できます。編集欄内では対象文字の前後に`==`が表示され、下のプレビューと保存後の各画面では黄色のマーカーとして表示されます。

学習記録はブラウザのローカルストレージに保存されます。別の公開先や端末へ移る場合は、アプリの設定画面からCSVを書き出し、新しい環境で読み込んでください。
