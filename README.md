# 予備試験 合格管理 — 2026年10月18日版

復習方法を対話で再検討するため、「復習」ページをいったん削除しました。

- パソコン・iPad・スマートフォンのメニューから「復習」を削除。
- ホームの「今日の復習」、今日の学習の復習入力、直近10問の復習状況表示も削除。
- 過去の復習予定・再現履歴・理解度テスト・弱点分類などは、更新前のバックアップに退避して現行データから除去。
- 短答・論文の新規登録時に復習予定を自動生成しません。
- 学習履歴、答案・コメント、〈論証〉を含む元コメント、進捗表示、週間レビュー、目標設定は維持。

同じ公開URL・同じブラウザの保存データを継続利用します。旧CSV・旧JSONの学習履歴も読み込めます。読み込んだファイルに復習データが含まれている場合はバックアップに退避し、現行の復習履歴には再登録しません。

更新後に初めて開いた際、削除前の全データをブラウザ内の `yobishiken-removed-reviews-2026-10-18` に保存します。設定→完全バックアップ・復元→自動バックアップの「復習ページ削除前の全記録」から書き出せます。ブラウザ消去に備え、必要に応じてファイルとしても保管してください。以前の更新前バックアップも保持します。

個人の学習CSV・JSONは公開リポジトリに含めません。端末間の自動同期はありません。

## 配置

`index.html`、`README.md`、`vercel.json` をGitHubリポジトリのルートに置きます。VercelではOther・ビルドなし・出力ディレクトリ `.` を使います。
