# 予備試験 合格管理 — 2026年10月15日 かんたん版

既存の2026年9月27日版に、重要問題の学習・復習記録を追加しました。
`index.html` はCSS・JavaScript・画像を内包した単一ファイルです。ビルドは不要です。

## 普段の使い方（転記・文章入力を減らしました）

1. 「今日の学習」で重要問題を従来どおり登録します。
2. 「かんたん学習・復習」で、自信度（30・60・90の目安）と時間不足の有無をタップします。実測時間の初期値は40分。不安な論点などの記述は任意です。
3. 添削・解説を確認したら「添削・解説を確認したので復習を始める」を押します。既存コメントの `<論証>...</論証>` を自動で使うため、GPT回答を別の欄に貼り直す必要はありません。
4. 口頭や紙で規範とあてはめを再現し、「口頭・紙で再現した → 答えを見る」で比較して、「出なかった」「一部できた」「自力でできた」のいずれかを押します。文章入力は任意です。
5. 翌日・7日後は画面上部に復習対象が出ます。1回の操作で別の日の復習を完了にしません。未来の予定はその日になってから記録します。

かんたん画面の入力・選択は自動保存されます。口頭・紙の再現は、本人の自己申告として履歴に残ります。AIが採点・認定したことにはしません。資料を先に見た場合も記録できます。

弱点のA〜E分類は任意で複数選択できます。分類された場合は一般的な学習改善課題を補います。条文や法律上の規範をアプリが推測して生成することはありません。新方式の「未定着・要復習・定着」、ホームと週間レビューの直近10問の表示も継続します。

## GPT回答を使いたい場合（任意の一括取り込み）

「GPTの回答をまとめて取り込む」から専用プロンプトをコピーし、問題文・模範答案・自分の答案と一緒にChatGPTへ送ってください。回答全体を1回貼り、取込内容を確認して保存すると、最重要論点・規範・あてはめ・弱点・次回改善課題・理解度テストの問いをまとめて取り込みます。

専用プロンプトは回答末尾に問題ID付きのJSONブロックを出すよう指示します。問題IDが異なる回答や途中で切れた取込データは拒否します。通常の回答は `<論証>` 部分だけを取り込めます。取込形式もタグもない場合は、本人が確認して回答全文を復習メモとして保存できます。弱点を勝手に分類しません。

取り込み前に自動バックアップします。既存のテストの問い・回答・採点・再現履歴・復習の起点日は保持します。新たな問いは空いているテスト欄に入れます。貼り付け途中の文章も自動保存します。外部AIとの自動通信はありません。

細かく入力したい場合は「詳しい入力・理解度テスト・採点」を開くと、以前の画面を利用できます。テストは回答を確定してから正解・得点・採点コメントを記録します。AI添削・採点はChatGPTで行い、その結果を記録する方式です。以前の詳細画面は各保存ボタンで確定します。

## 従来の論証タグ復習

2026年9月27日以降の従来復習は、`<論証>覚えたい内容</論証>` の内側を抽出します。複数のタグ・改行・黄色マーカーを保持します。タグなし、空のタグ、閉じ忘れは対象外です。9月26日以前は従来どおりです。
新しい重要問題の学習・再現記録はタグの有無にかかわらず登録できます。従来のタグ復習記録と新方式の再現履歴はそれぞれ保持します。

## データ移行・バックアップ・復元

- 同じ公開URL・同じブラウザの `yobishiken-study-v1` 保存領域を継続利用します。旧履歴を自動で新方式の完了に変更しません。
- かんたん版への更新前データも `yobishiken-pre-quick-2026-10-15` として別保存します。設定のバックアップ一覧から復元できます。
- 更新前のブラウザ保存データは、初回読込時に `yobishiken-pre-learning-v2` として別保存します。読み込めない元データは自動で上書きしません。
- 旧CSVをそのまま読み込めます。書出ファイル名は `予備試験学習記録2026.csv` のままです。末尾の `essay_learning` 列に新方式の記録をJSON形式で追加します。新CSVはこの更新版で復元してください。旧版は追加列を無視するため、新記録を保持できません。
- CSV読込・JSON復元・初期化の前に、現在のデータを自動バックアップします。直近5件と更新前の原本を保持します。設定から確認・書出・復元できます。
- 設定の「JSON完全バックアップ」は全履歴・設定・理解度テスト・再現答案を保存します。復元前に日数・論文問数・短答件数を確認できます。
- 自動バックアップも同じブラウザ内です。ブラウザのデータ消去に備え、JSONをiCloud等へ定期的に書き出してください。
- 別端末・別ブラウザ・別URLではCSVまたはJSONで移行します。自動クラウド同期はありません。
- 添付された学習CSVおよび移行JSONは公開ファイルに含めていません。非公開バックアップフォルダに別保存しています。
